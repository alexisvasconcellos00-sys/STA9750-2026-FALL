What We Watched: Where Netflix’s Viewing Hours Go

Building the Viewing Record (Task 1)

Netflix’s What We Watched reports provides underlying data of Netflix’s most watched shows on its platform. The report combines seven half-year reports, from 2023H1 through 2026H1, and caches the workbooks locally.

Code 
library(tidyverse)
library(rvest)
library(readxl)
library(fs)

load_netflix_data <- function() {
  data_dir <- fs::path("data", "mp01")
  fs::dir_create(data_dir)

  report_urls <- c(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )

  paths <- fs::path(data_dir, paste0(names(report_urls), ".xlsx"))
  for (i in seq_along(paths)) {
    if (!fs::file_exists(paths[[i]])) {
      page <- rvest::read_html(report_urls[[i]])
      link <- page |>
        rvest::html_element(xpath = "//a[contains(@href, '.xlsx')]") |>
        rvest::html_attr("href")
      if (is.na(link)) {
        stop("No Excel report link found for ", names(report_urls)[[i]])
      }
      download.file(link, paths[[i]], quiet = TRUE, mode = "wb")
    }
  }

  purrr::map2_dfr(paths, names(report_urls), function(path, period) {
    readxl::read_excel(path, skip = 3, na = "*") |>
      mutate(`Release Date` = as.Date(`Release Date`), period = period)
  }) |>
    mutate(
      year = stringr::str_sub(period, 1, 4),
      half = stringr::str_sub(period, start = 6),
      period_start = lubridate::make_date(year, if_else(half == "1", 1, 7), 1),
      period_end = lubridate::make_date(year, if_else(half == "1", 6, 12),
                                        if_else(half == "1", 30, 31))
    ) |>
    filter(!is.na(`Hours Viewed`)) |>
    mutate(
      live_event = !is.na(Runtime) & stringr::str_detect(Runtime, "\\d+:\\d+\\*"),
      clean_time = stringr::str_remove(Runtime, stringr::fixed("*")),
      Runtime = 60 * lubridate::hour(lubridate::hm(clean_time)) +
        lubridate::minute(lubridate::hm(clean_time))
    ) |>
    select(-clean_time) |>
    mutate(
      Runtime = coalesce(Runtime, mean(Runtime, na.rm = TRUE)),
      .by = Title,
      Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
      Title = stringr::str_remove(Title, " // .*"),
      Title = stringr::str_remove(Title, "[^[:ascii:]].*"),
      Title = stringr::str_trim(Title)
    ) |>
    filter_out(Title == "") |>
    select(year, period, period_start, period_end, Title, -half,
           Runtime, Views, `Hours Viewed`, `Release Date`,
           `Available Globally?`, live_event)
}

1. How Far does this Viewing History reach?

The data covers viewing from January 2023 through June 2026. These are reporting periods, so the hours for a title refer to a particular half-year.

2. How many Different Titles appear?

I found 24,427 different title names in the imported data. Different seasons can count as separate titles.

3. What does the Bridgerton Universe add up to?

The main Bridgerton seasons and Queen Charlotte: A Bridgerton Story add up to 4,860,400,000 hours viewed across the available periods. I left out the related afterparty and fireplace titles as they are separated from the show.

4. How Much Time Went to Hawkins?

The five main seasons of Stranger Things add up to 5,548,500,000 hours viewed. I excluded Beyond Stranger Things, Tales From ’85, and the fireplace title because the question asks for the five seasons.

5. Do Ten Hits Dominate 2026H1?

The top ten individual titles made up 6.1% of the imported watch hours in 2026H1. That is a small share, which means most viewing was spread across other titles. I kept Other Shows in the total hours but did not treat it as one individual title in the top ten.

6. Does Global Availability align with Watch Time?

Globally available titles made up 24.6% of the distinct titles in the imported data but received 51.9% of its watch hours. I can see a relationship here, although the data does not show that global availability caused the difference.

How much Viewing goes to Shows versus Movies?

content_mix_2023h1 <- NETFLIX_DATA |>
  filter(period == "2023H1") |>

      period = current_period,

        summarise(hours_viewed = sum(`Hours Viewed`, na.rm = TRUE)) |>
        pull(hours_viewed)
    )
  })
})

Platform Strategy Memo (Task 7)

To: Netflix Content Leadership
Subject: Priorities for the 2027 Original-Content Slate

The Recommendation

Based on the viewing data, I would give streaming series an important place in Netflix’s 2027 plans, while still keeping movies in the budget. I would also look for titles that people continue watching across several periods instead of relying only on one big opening.
